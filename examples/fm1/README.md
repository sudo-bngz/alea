# Patches for the FM-1

Works whose `output` is a `synth { … }`, for `alea … --fm1`: a bass, a pad, a bell and a dub stab (the ALEA
engine's four factory patches are these, at `--seed` 7, 1, 3 and 2). See
[`fm1/README.md`](../../fm1/README.md). `-n 8` compiles eight editions into one bank: eight patches,
each with its own draws.
