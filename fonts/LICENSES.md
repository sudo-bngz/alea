# Built-in fonts

These fonts are embedded in the alea binary so that `text()` works out of the box.

| Name in alea | Font | Licence |
|---|---|---|
| `sans` | Poppins Regular (Indian Type Foundry) | SIL Open Font License 1.1 |
| `bold` | Poppins Bold (Indian Type Foundry) | SIL Open Font License 1.1 |
| `serif` | Lora (Cyreal) | SIL Open Font License 1.1 |
| `mono` | DejaVu Sans Mono | Bitstream Vera / DejaVu licence (free) |

The SIL Open Font License allows the fonts to be bundled and redistributed with
software, provided they are not sold on their own. Full texts:
https://openfontlicense.org and https://dejavu-fonts.github.io/License.html
