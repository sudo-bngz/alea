01Chance is part of the language

An alea program describes a family of artworks. Where you would write a number, you can write a distribution instead: ~between(0.25, 0.4) lets alea decide, once per edition. ~~ decides again at every point of the picture, and choose picks between whole structures.

Then you say what to make of it. The same work can render an image, a looping video, a sound, a sculpture to print in 3D, or a MIDI score that plays in your DAW. Works can use other works as parts, open their own files (photos, sounds, texts, MIDI files), take an input, read from a pipe, and go on a timeline, scene after scene, with glitches, morphs and fades between them.

It is written for artists first: no setup to try it, plain words for its functions, and error messages that say how to fix the problem.

work Network {
  let nodes = [[~between(0.08, 0.92), ~between(0.08, 0.92)] for k in range(30)]
  let hub   = [~between(0.35, 0.65), ~between(0.35, 0.65)]

  let links = choose {
      [line(p.x, p.y, q.x, q.y, 0.002) * max(0, 1 - distance(p, q) / 0.3)
         for p in nodes for q in nodes]                             // a mesh
    | [line(p.x, p.y, hub.x, hub.y, 0.002) * 0.7 for p in nodes]   // a star
    | [path(join(nodes, [nodes[0]]), 0.002) * 0.7]                 // a loop
  }
  let dots  = [circle(p.x, p.y, ~between(0.008, 0.02), 0.002)
               for p in join(nodes, [hub])]

  render image(merge(join(links, dots)), palette: "night")
}

02Install

In the browser

Nothing to install: the playground runs alea, with examples and the tour of the language.

macOS and Linux

brew install sudo-bngz/tap/alea

With Rust

cargo install alea-lang

Any system

The latest release has alea for macOS, Linux and Windows, and the plugin for Ableton Live and other DAWs (VST3, CLAP).

alea isohypses.alea              # one edition: isohypses-<seed>.png
alea isohypses.alea -n 6         # six editions
alea isohypses.alea --seed 0x2a  # edition 0x2a, again

Then read the handbook: the guide, one idea per chapter, and the reference.
