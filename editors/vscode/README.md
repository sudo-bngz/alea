# alea for VS Code

Syntax highlighting and snippets for `.alea` files.

Install: `code --install-extension alea-lang-0.14.0.vsix`

Highlights keywords (`use`, `work`, `output`, `let`, `field`, `pattern`, `constraint`, `render`,
`repeat`, `event`, `choose`), the draw operators `~` and `~~`, distributions,
primitives (`circle`, `stripes`, `rotate`…), calls to other works, built-in functions, aggregates, render kinds, named arguments, `x y t i n`,
`pi tau`, numbers, strings and comments.

Snippets: `work`, `pattern`, `choose`.
